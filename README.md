🌍 GLOBAL WELLNESS CHATBOT - USING AI 
 
 # 📘 Overview 
 Global Wellness Chatbot is an AI powered chatbot that gives users clear , simple and multilingual health information , sourced from trusted public resources. It focuses on wellness, common ailments and first aid guidance while reminding users to consult medical professionals for diagnosis and treatment.

 # 🎯 Objectives
- Develop an AI-powered chatbot featuring a user-friendly Streamlit interface and multilingual interaction support in English and Hindi.
- Implement Natural Language Understanding (NLU) and intent recognition to accurately interpret user queries and manage conversational flow.
- Integrate a trusted health knowledge base to provide reliable, ethical, and easy-to-understand information on wellness, common ailments, and first aid.
- Develop an admin dashboard for the administrator to monitor analytics, manage health tips, and oversee chatbot performance.

# ⚙️ Features
- AI-based chatbot for user health queries.
- Bilingual support (English & Hindi).
- Dynamic knowledge base with CRUD operations.
- Admin dashboard for managing health conditions.
- SQLite-based data storage.
- Health disclaimers for each condition.

# 🧰 Tech Stack
Frontend          : Streamlit
Backend           : Python
Database          : SQLite
AI Frameworks     : Hugging Face Transformers
Language Models   : Helsinki-NLP/opus-mt-en-hi
